# Bloc Admin UI

Frontend application for apartment building administration built with React, TypeScript and Vite.

The platform provides dedicated interfaces for administrators and residents, focused on financial management, utility tracking and communication.

---

## ✨ Features

### 👨‍💼 Administrator
- Dashboard overview
- Block management
- Resident management
- Financial management
- Water consumption tracking
- Reports and exports
- Application settings

### 🏠 Resident
- Personal dashboard
- Bills and payments
- Water index submission
- Personal settings

### 🌍 General
- Responsive UI
- Dark / Light mode
- Multi-language support (i18n)
- Role-based interface
- Type-safe architecture

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Material UI (MUI)
- React Router
- i18next

## 🚀 Getting Started

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Production build

```bash
npm run build
```
